## Part 2. Создание пользователя

- Создать пользователя можно с помощью команды `sudo adduser user_name`

> Создание пользователя *user_for_part_2* \
![alt text](screenshot/2_1.png)

- Добавление пользователя в группу можно осуществлять с помощью команды `usermode` с флагами `-aG`
- Флаг `-a` используется для добавления пользователя в дополнительные группы, не удаляя его из уже существующих групп. Без этого флага пользователь будет удален из всех групп, кроме указанной. Используется только в связке с флагом `-G`
- Флаг `-G` указывает список групп, в которые мы хотим добавить пользователя. Группы перечисляются через запятую без пробелов

- Посмотреть список (названия) сетевых интерфейсов можно различными способами. Например с помощью команды `ip link show` или командой `ip addr show` *(для получения более подробной информации)*, также можно посмотреть содержимое файла `/proc/net/dev` или с помощью команды `ifcongig` из пакета *net-tools*. Воспользуемся последним.

> Установка пакета *net-tools* и просмотр сетевых интерфейсов \
![Установка пакета *net-tools* и просмотр сетевых интерфейсов](screenshot/3_3.png)

- Мы видим два сетевых интерфейса `enp0s3` и `lo`
- `enp0s3` - это имя Ethernet-интерфейса. Этот интерфейс обычно используется для подключения к сети (например, к локальной сети или интернету)
- `lo` - это интерфейс "loopback" (петлевое соединение). Он используется для связи внутри самой системы. Он часто используется для тестирования и отладки сетевых приложений, а также для обеспечения работы некоторых служб, которые могут обращаться к себе

- Получить ip адрес устройства можно указав его вручную или автоматически от DHCP-сервера.
- `DHCP` (Dynamic Host Configuration Protocol) — это сетевой протокол, который автоматически назначает IP-адреса и другие параметры конфигурации сетевым устройствам в локальной сети. Это позволяет устройствам подключаться к сети и получать необходимые настройки без необходимости ручной конфигурации.
- Получим ip адрес устройства автоматически. 
- Для этого сначала освободим существующий (уже присвоенный при старте системы) ip адрес с помощью команды `sudo dhclient -r enp0s3`, после чего удостоверимся в этом командой `ifcongig` описанной ранее
- Флаг `-r` в команде `dhclient` используется для указания, что мы хотите освободить (release) IP-адрес, который был назначен нашему сетевому интерфейсу DHCP-сервером

> Освобождение ip адреса \
![Освобождение ip адреса](screenshot/3_4_1.png)

- Получить новый ip адрес можно командой `sudo dhclient enp0s3`

> Получение ip адреса \
![Получение ip адреса](screenshot/3_4_2.png)

- Для получения ip-адрес шлюза (ip) и внутреннего IP-адрес шлюза, он же ip-адрес по умолчанию (gw) воспользуемся командами `curl ifcongig.me` и `ip route` соответсвенно.
- Команда  `curl ifcongig.me` отправляет HTTP-запрос к ifconfig.me, и сервер отвечает, возвращая наш внешний IP-адрес
- Команда `ip route` выводит текущую таблицу маршрутизации. Мы можем увидить, что для доступа к адресам, не входящим в локальную сеть, используется шлюз `10.0.2.2` через интерфейс *enp0s3*

> Получение внешнего и внутренного ip адреса шлюза \
![Получение внешнего и внутренного ip адреса шлюза](screenshot/3_5.png)

- Задать статичные (заданные вручную, а не полученные от DHCP-сервера) настройки ip, gw, dns можно вручную отредактировав файл в папке /etc/netplat/***.yaml или воспользовавшись утилитой nmtui из пакета network-manager
- Отрекдактируем файл */etc/netplan/00-installer-config.yaml* задав свободный ip адрес, gw, а также публичные DNS-серверы, например 1.1.1.1 или 8.8.8.8

![Редактируем файл */etc/netplan/00-installer-config.yaml*](screenshot/3_6_1.png)

## Part 5. Использование команды **sudo**

- `sudo` — программа для системного администрирования UNIX-систем, позволяющая делегировать те или иные привилегированные ресурсы пользователям с ведением протокола работы. Основная идея — дать пользователям как можно меньше прав, при этом достаточных для решения поставленных задач. Программа поставляется для большинства UNIX и UNIX-подобных операционных систем. Команда sudo предоставляет возможность пользователям выполнять команды от имени суперпользователя root.
- Для того, чтобы наш пользователь созданный в [Part 2](#part-2-создание-пользователя), мог выполнять команду `sudo` его необходимо наделить соответсвующими права.

## Part 6. Установка и настройка службы времени

- В Linux существует несколько служб и протоколов для синхронизации времени. Среди наиболее распространенных имеются `ntpd` и `systemd-timesyncd`.
- `ntpd` это основной демон для синхронизации времени с использованием протокола NTP. Он поддерживает синхронизацию времени с удаленными NTP-серверами и может также работать как сервер для других клиентов
- `systemd-timesyncd` это легковесный клиент для синхронизации времени, который является частью системы `systemd`. Он автоматически синхронизирует системное время с NTP-серверами, если они указаны в конфигурации
- Воспользуемся и настроим последнего, так как он уже был установлен в системе по умолчанию 😛

- Для начала проверим что служба `systemd-timesyncd` активна командой `systemctl status systemd-timesyncd`

> Проверка состояния службы `systemd-timesyncd` \
![Проверка состояния службы systemd-timesyncd](screenshot/6_1_1.png)

- После чего зададим необходимую конфигурацию в файле `/etc/systemd/timesyncd.conf`

> Редактирование файла `/etc/systemd/timesyncd.conf` \

- После всех манипуляций не забываем перезагрузить систему `sudo reboot`

- Посмотреть наличие процесса `sshd` можно командой `ps aux | grep sshd`

> Вывод команды `ps aux | grep sshd` \
![Вывод команды `ps aux | grep sshd`](screenshot/8_1.png)

- В данном случае команда `ps` (process status) используется для отображения текущих процессов, работающих в системе. Она предоставляет информацию о запущенных процессах, таких как их идентификаторы (PID), состояние, использование ресурсов и т.д.
- Параметры `aux`:
- `a`: Показывает процессы всех пользователей, а не только текущего пользователя. Это позволяет увидеть процессы, запущенные другими пользователями
- `u`: Выводит информацию в удобочитаемом формате, включая имя пользователя, использующий процесс, и использование ресурсов (CPU и память)
- `x`: Показывает процессы, не привязанные к терминалу. Это полезно для отображения фоновых процессов, таких как демоны
- Символ `|` (пайп) используется для передачи вывода одной команды в качестве ввода для другой команды. В данном случае вывод команды `ps aux` передается в команду `grep`
- Команда `grep` используется для поиска строк, соответствующих заданному шаблону. В данном случае `grep sshd` ищет строки, содержащие `sshd` в выводе команды `ps aux`

- Для получения информации о сетевых соединениях воспользуемся командой `netstat -tan`

> Вывод команды `netstat -tan` \
![Вывод команды netstat -tan](screenshot/8_2_2.png)

- `netstat` (network statistics) — это утилита командной строки, которая отображает сетевую статистику, включая активные соединения, таблицы маршрутизации, интерфейсы и т.д.
- Параметр `-tan`:
- `t`: Этот параметр указывает `netstat` отображать только TCP-соединения
- `a`: Этот параметр указывает отображать все соединения и прослушивающие порты (LISTEN)
- `n`: Этот параметр указывает выводить адреса и номера портов в числовом формате, а не разрешать их в имена хостов и сервисов. Это ускоряет вывод и делает его более понятным, особенно в случае, если DNS-серверы недоступны

Полученный вывод содежит в себе заголовок **Active Internet connections (servers and established)**.  Он указывает, что вывод содержит активные интернет-соединения, включая серверные и установленные соединения и содержит следующие столбцы:
- `Proto`: Протокол, используемый для соединения (например, tcp или tcp6 для IPv6).
- `Recv-Q`: Количество байтов, ожидающих обработки в очереди получения. Если это значение больше нуля, это может указывать на проблемы с производительностью.
- `Send-Q`: Количество байтов, ожидающих отправки в очереди отправки. Если это значение больше нуля, это может указывать на проблемы с сетью или перегрузку.
- `Local Address`: Локальный адрес и порт, на котором работает служба. Формат: IP:PORT.
- `Foreign Address`: Удаленный адрес и порт, с которым установлено соединение. Если соединение прослушивает, здесь будет *.
- `State`: Состояние соединения. Возможные состояния **LISTEN**: Служба прослушивает входящие соединения на указанном порту и **ESTABLISHED**: Соединение установлено и активно
- Значение 0.0.0.0 (любой адрес) указывает что служба, работающая на этом порту (2022), настроена для прослушивания входящих соединений от любых клиентов

## Part 12. Использование утилиты **du**

- Для отображения объема дискового пространства, занимаемого файлами и директориями воспользуемся командой `du`. Для вывода в человекочитаемом формате необходимо воспользоваться флагами `-bh`.
- `b`: Этот флаг указывает утилите du выводить размеры в байтах. Это означает, что размеры файлов и каталогов будут отображаться в абсолютных единицах, без преобразования в более крупные единицы (килобайты, мегабайты и т.д.).
- `h`: Этот флаг означает "человеко-читаемый" формат. Он позволяет выводить размеры в удобочитаемом формате, автоматически выбирая подходящие единицы (килобайты, мегабайты, гигабайты и т.д.) в зависимости от размера
