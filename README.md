Комплексный репозиторий из 6 практических инженерных проектов, охватывающих полный спектр задач DevOps-инженера, SRE и системного администратора Linux: низкоуровневое конфигурирование ядра и служб операционной системы, проектирование и маршрутизацию распределенных корпоративных сетей, автоматизацию системного мониторинга на Bash, стресс-тестирование дисковых подсистем, аналитику веб-логов, контейнеризацию микросервисов с аудитом безопасности Dockle и построение отказоустойчивого производственного конвейера CI/CD.

---

## Обзор портфолио

Репозиторий представляет собой последовательную систему прикладных инженерных задач, моделирующих реальные сценарии эксплуатации серверной инфраструктуры — от базовой инициализации физических/виртуальных серверов до автоматизированной доставки кода на удаленные целевые узлы с мгновенным оповещением команды.

Все проекты выполнены с соблюдением отраслевых стандартов надежности, принципов Infrastructure as Code (IaC), строгой валидации входных параметров, безопасности сетевого периметра и изоляции процессов.

---

## Ключевые компетенции и стек технологий

- **Системное администрирование Linux (GNU/Linux):** управление процессами и службами (`systemd`, `systemctl`, `init`, сигналы `kill`/`pkill`, приоритеты `nice`/`renice`), разграничение прав доступа и аутентификация (`PAM`, `sudoers`, POSIX permissions, sticky bit, SUID/SGID), подсистема хранения данных (`fdisk`, `mkfs`, монтирование, управление таблицей разделов, контроль inodes, анализ дискового пространства утилитами `df`, `du`, `ncdu`), планировщик регламентных заданий (`cron`, `crontab`), синхронизация времени (`timedatectl`, `systemd-timesyncd`, NTP), аудит и системное логирование (`journalctl`, `syslog`, `auth.log`, `last`).
- **Сетевая инфраструктура и сетевая безопасность:** бесклассовая адресация (CIDR, расчет масок и подсетей через `ipcalc`), декларативное управление сетью через Netplan (YAML), статическая и динамическая маршрутизация между изолированными подсетями, ядровой IP forwarding (`sysctl net.ipv4.ip_forward=1`), межсетевые экраны и пакетная фильтрация (`iptables` таблицы `filter` и `nat`, цепочки `INPUT`, `OUTPUT`, `FORWARD`, `PREROUTING`, `POSTROUTING`), трансляция сетевых адресов (SNAT/MASQUERADE и проброс портов DNAT), автоматическая конфигурация сетевых узлов через DHCP (`isc-dhcp-server`), диагностика сетевой связности и пропускной способности (`tcpdump`, `traceroute`, `ping`, замеры полосы пропускания `iperf3`), организация безопасных SSH-туннелей (Local и Remote Port Forwarding).
- **Автоматизация и Bash-скриптинг:** разработка модульных отказоустойчивых скриптов на Bash 5+, строгая валидация CLI-аргументов регулярными выражениями, динамическая стилизация терминального вывода (ANSI escape codes), парсинг псевдофайловых систем `/proc` и `/sys`, конвейерная потоковая обработка текстов (`awk`, `sed`, `grep`, `cut`, `sort`, `uniq`), алгоритмы комбинаторной генерации сущностей, потоковое вычисление контрольных сумм файлов (MD5), прецизионные замеры времени выполнения процессов с наносекундной точностью.
- **Контейнеризация и оркестрация:** контейнеризация приложений на Docker (жизненный цикл контейнеров, слои OverlayFS, оптимизация размера слоев в Dockerfile), разработка легковесного веб-сервера FastCGI на языке C (`fcgiapp.h`, `spawn-fcgi`), интеграция с Nginx (`proxy_pass`, `fastcgi_pass`, модуль `stub_status`), безопасность контейнеров (запуск от непривилегированного пользователя, соответствие стандартам CIS Docker Benchmark, аудит уязвимостей через линтер `dockle`), декларативная мультиконтейнерная оркестрация через Docker Compose.
- **Observability, мониторинг и аудит логов:** контролируемое стресс-тестирование и заполнение накопителей (`fallocate`, `truncate`, контроль пороговых значений свободного места в 1 Гб), стратегии автоматизированной очистки файловых систем (по журналам генерации, временным меткам, маскам имен), синтез журналов веб-сервера в формате Nginx Combined Log Format, глубокая аналитическая фильтрация логов на AWK, построение интерактивных аналитических веб-отчетов через GoAccess, развертывание и конфигурирование стека метрик (Prometheus pull-модель, Node Exporter, дашборды Grafana).
- **Непрерывная интеграция и доставка (CI/CD):** проектирование и развертывание многостадийных пайплайнов в `.gitlab-ci.yml` (стадии `build`, `style_check`, `test`, `deploy`), управление жизненным циклом артефактов сборки (`artifacts`, `expire_in`), автоматизированный статический анализ качества кода (Google Style via `clang-format` в строгом режиме `-n -Werror`), интеграционное тестирование CLI-утилит на Bash, организация безопасного беспарольного деплоя на целевой production-сервер по SSH/SCP с ручным подтверждением (`when: manual`), мониторинг статуса выполнения джобов и нотификации в Telegram через Telegram Bot API (`after_script` вебхуки).

## Требования и инструкция по быстрому старту

### Системные требования
- **Операционная система:** Linux (рекомендуется Ubuntu 20.04 LTS или выше);
- **Командные оболочки:** GNU Bash 5.0+;
- **Базовый инструментарий:** GNU Coreutils, `awk`, `sed`, `curl`, `iproute2`, `net-tools`;
- **Контейнеризация:** Docker Engine 20.10+, Docker Compose v2+;
- **CI/CD раннер:** GitLab Runner (для воспроизведения распределенного пайплайна);
- **Линтеры и компиляторы:** `gcc`, `clang-format`, `make`.

### Быстрый старт

1. **Клонирование репозитория:**
   ```bash
   git clone <url-репозитория>
   cd <каталог-репозитория>
   ```

2. **Запуск скриптов системного мониторинга (DO3):**
   ```bash
   # Вывод базовой телеметрии системы с сохранением в лог
   cd DO3_LinuxMonitoring_v1_0_ID_356278-3-develop/src/02
   bash main.sh

   # Анализ файловой структуры каталога
   cd ../05
   bash main.sh /var/log/
   ```

3. **Запуск стресс-тестирования и стека метрик (DO4):**
   ```bash
   # Развертывание Prometheus и Grafana через Docker Compose
   cd DO4_LinuxMonitoring_v2_0_ID_356280-1-develop/src/07
   docker compose up -d
   ```

4. **Сборка и запуск контейнеризованного FastCGI-сервера (DO5):**
   ```bash
   # Запуск multi-container стека с Reverse Proxy
   cd DO5_SimpleDocker.ID_356282-1-develop/src
   docker compose up --build -d
   curl http://localhost:80/
   ```

5. **Тестирование конвейера сборки и интеграционных тестов (DO6):**
   ```bash
   # Локальный прогон тестов приложения
   cd DO6_CICD.ID_356283-1-develop/src
   bash test.sh
   ```
